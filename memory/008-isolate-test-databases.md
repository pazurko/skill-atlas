# Isolate Test SQLite Databases and Prevent User Cache Pollution

- **Status**: Implemented
- **Date**: 2026-10-01
- **Author/Agent**: Junie
- **PR / Issue Reference**: Isolate Test Databases

---

## 1. Context & Motivation
- When running automated test suites (`cargo test`), tests in `tests/scanner_test.rs` previously instantiated `ScannerOptions` with `db_path: None`.
- In `src/scanner.rs` and `src/storage.rs`, `db_path: None` resolves to `default_db_path()` (`~/.skill-atlas/skills.db`).
- Whenever scanner tests executed (such as mock tests scanning `acme/many` and `acme/big`), mock test skills were saved into the user's primary SQLite database, causing test fixture skills (`skill-00`..`skill-39`, `deploy`) to re-appear in the user's catalogue after test runs.

---

## 2. Requirements & Specification
- All integration tests invoking repository scanners or database storage must provide an isolated temporary database path (in `std::env::temp_dir()`).
- All temporary database files generated by tests must be cleaned up following test completion.
- Running `cargo test` must never write to or modify `~/.skill-atlas/skills.db`.

---

## 3. Architecture & Implementation Details
- `tests/scanner_test.rs`: Updated `test_scan_github_repo_not_found_404`, `test_scan_github_repo_forbidden_rate_limit_403`, `test_scan_head_uses_repository_default_branch_in_urls`, `test_scan_head_falls_back_to_head_ref_when_default_branch_unknown`, `test_scan_downloads_only_skill_files_concurrently_in_order`, and `test_scan_falls_back_to_blob_api_and_reports_truncated_tree` to use unique temporary database paths with automatic cleanup.
- Cleaned any remaining mock `acme` test fixture records from `~/.skill-atlas/skills.db`.

---

## 4. Testing & Verification
- Ran full test suite via `cargo test` (all 74 unit and integration tests passing).
- Verified that `~/.skill-atlas/skills.db` only contains authentic scanned repositories and does not get re-polluted when running `cargo test`.
- Verified formatting and linting via `cargo fmt -- --check` and `cargo clippy --all-targets -- -D warnings`.
